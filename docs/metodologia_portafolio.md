# Nota metodológica

El Atlas parte de una premisa sencilla: una cifra nacional de conectividad no describe adecuadamente la desigualdad territorial.

La lectura distingue al menos dos planos. El primero es la **severidad**, medida a partir de la proporción de hogares afectados dentro de cada territorio. El segundo es el **volumen**, que observa el número absoluto de hogares afectados. Una comuna puede tener una tasa elevada y un volumen reducido, mientras otra puede mostrar una tasa menor pero concentrar miles de hogares sin conexión.

La versión completa incorpora otras dimensiones de acceso y vulnerabilidad digital. Esas especificaciones no se publican en este repositorio de portafolio.

## Criterios de publicación

- Se usan únicamente resultados seleccionados.
- No se publican microdatos.
- No se entrega la base comunal completa.
- No se incluyen fórmulas suficientes para reconstruir el índice completo.
- Los indicadores derivados deben leerse en conjunto con sus universos y denominadores originales.
