# Fuentes y trazabilidad

La versión completa del Atlas se construye a partir de fuentes oficiales y procesamiento propio.

Fuentes principales:
- Censo de Población y Vivienda 2024.
- CASEN 2024.
- SUBTEL.
- Cartografía administrativa oficial.

Este repositorio no redistribuye las bases originales de terceros. Las cifras publicadas corresponden a resultados seleccionados del procesamiento del Atlas.
